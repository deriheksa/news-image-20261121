# news-image-20261121 — One Day of World News, One Picture

Entry for the [news-image-20261121 bounty](https://make.fun/bounty/news-image-20261121):
sum up Saturday 21 November 2026's world news in a single image.

A one-page newspaper on warm cream paper: 44 verified stories across
7 regions — 4 illustrated heroes (Bahrain, Kryvyi Rih, Hormuz, COP31),
11 grid cards, 29 ALSO briefs, a "WHERE IT HAPPENED" world map with
pins 1–15 and dots 16–44, a region bar, a "THE DAY IN NUMBERS" strip,
and a DATE CHECK box listing stories deliberately left out with their
dates. Every story was cross-checked against at least two sources;
contested claims are flagged.

`main.py` copies the pre-rendered `entry.jpg` to `/output/entry.png`
using only the Python standard library.
